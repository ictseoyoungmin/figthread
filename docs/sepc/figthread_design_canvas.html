Figthread / semantic figure authoring system

Design baseline · v1.0 · D-001–D-009 closed

One explanatory thread,
from claim to motion.

Figthread는 데이터·개념·알고리즘·시스템 구조를 publication/presentation-ready figure로 설계하고, 필요한 경우 SVG/HTML 기반의 정밀한 시간적 표현으로 그 논리의 흐름을 확장하는 skill이다. Figure가 본체이고 motion은 의미 전달을 강화하는 수단이다.

Primary quality question

독자가 저자의 추가 설명 없이 의도된 thread를 따라갈 수 있는가?

Motion quality question

움직임이 그 thread를 더 명확히 드러내는가, 아니면 장식하는가?

Default artifact

Canonical single HTML · deterministic timeline · on-demand SVG/PNG derivatives.

01 · CORE

Identity and non-negotiables

Figthread가 단순한 HTML 다이어그램 프롬프트 모음으로 퇴화하지 않도록, 작업 순서와 품질 판단의 기준을 먼저 고정한다.

Locked baseline5 principles
01 · Figure first

Figure first, motion second.

애니메이션을 제거해도 핵심 claim과 구조가 이해되어야 한다. Motion은 정적 figure의 결함을 감추는 보정층이 아니다.

02 · Semantics first

Semantic structure before SVG.

DOM 좌표나 CSS부터 작성하지 않는다. Claim → semantic figure IR → layout → motion IR 순으로 권한을 내려보낸다.

03 · Meaningful motion

Motion must encode meaning.

fade·translate 같은 효과명보다 arrive·route·accumulate·persist 같은 상태 의미가 먼저 정의되어야 한다.

04 · Evidence

Render the exact artifact.

코드가 맞다고 품질을 가정하지 않는다. 지정된 keyframe과 target size를 실제 렌더링해 눈으로 검증한다.

05 · Recovery

Repair causes, not symptoms.

후단 CSS 오프셋을 누적하지 않는다. 결함 원인이 claim, hierarchy, storyboard, layout 중 어디에 있는지 분류하고 해당 stage를 reopen한다.

Meta principle

Delete before adding.

모든 node, connector, label, color, motion은 독립적인 정보 역할을 가져야 한다. 제거해도 의미가 유지되면 제거 대상이다.

02 · MAP

End-to-end system map

소스에서 최종 single HTML까지의 권한 흐름. 아래 화살표는 단순 실행 순서가 아니라 무엇이 무엇의 authoritative input인지 나타낸다.

05 · MOTION IR

Motion as a deterministic semantic program

Motion IR은 CSS animation 목록이나 callback 집합이 아니다. FigureSpec의 상태 변화와 설명 사건을 시간축에 배치하고, ResolvedLayout을 참조해 재현 가능한 visual cue로 컴파일하는 선언형 program이다.

D-003 closedMotionSpec 0.1Declarative core

v0.1은 별도 declarative MotionSpec schema를 canonical motion authority로 채택한다. raw JavaScript callback은 MotionSpec에 들어갈 수 없으며, core certification을 유지하려면 등록된 pure extension compiler를 통해서만 확장한다. Canonical time은 integer millisecond이고, 어떤 시점의 frame도 이전 frame에 의존하지 않고 다시 계산할 수 있어야 한다.

D-003 decision. Meaning → state effects → visual cues → deterministic tracks 순서를 고정한다. Motion이 FigureSpec의 의미를 새로 만들거나 ResolvedLayout의 geometry를 임의로 수정해서는 안 된다. 재생은 stateful transport일 수 있지만 evaluate(time_ms) 자체는 pure하고 seek-safe해야 한다.

Time authority

Integer milliseconds are canonical

at_ms와 duration_ms는 non-negative integer다. normalized 0–1 time은 API convenience이며 Math.round(u × duration_ms)로 canonical time에 매핑한다.

  • wall-clock은 transport에만 사용
  • frame rate는 semantic state를 바꾸지 않음
  • same tick tie-break는 explicit order → ID
State authority

Evaluation is event-sourced

초기 snapshot에서 time_ms 이하의 effect를 stable order로 적용해 상태를 재구성한다. 이전 render frame의 DOM 값이나 누적 transform을 읽지 않는다.

  • seek = full semantic replay
  • beat checkpoint cache 허용
  • cache는 hash-bound optimization일 뿐 authority 아님
Visual authority

Cues cannot invent meaning

모든 cue는 EventSpec에 anchor되어야 하며, direct DOM selector나 임의 geometry를 가질 수 없다. cue는 semantic event를 읽히게 만드는 renderer instruction이다.

  • raw CSS keyframes는 compiled output
  • decorative-only core cue 금지
  • profile이 motion intensity ceiling을 결정

static mode

Not a frozen animation frame

static_snapshot_id가 가리키는 FigureSpec snapshot을 렌더한다. reduced-motion/print도 동일 source를 사용한다.

17 · D-008

Runtime / document closure

지금까지의 IR을 하나의 실행 가능한 문서 계약으로 묶는다. DOM은 authority가 아니며, 브라우저는 hash-verified FigthreadDocument를 deterministic하게 projection한다.

Canonical state와 compiled derivative, view-only ephemeral state를 분리한다. 문서가 열렸다는 이유만으로 성공으로 취급하지 않고 schema → compatibility → hash → registry → target → hydration을 모두 통과해야 READY다.

Meaning survives recompilation

Compiled

Target-specific immutable derivatives

Ephemeral

Never becomes authoring truth

DOM/SVG is a projection, not the source of truth. Runtime mutation may change the view, but cannot silently mutate FigthreadDocument.

Checkpoint rule

Checkpoint after promotion

모든 promoted stage 뒤에 lightweight checkpoint를 기록한다. checkpoint는 payload 복사본이 아니라 exact receipt/hash graph와 resume cursor를 저장한다.

Writer model

Single writer, many readers

v0.1에서는 한 coordinator만 promotion/reopen pointer를 변경한다. 보조 worker는 read-only analysis/evidence packet을 만들 수 있으나 authority를 직접 승격하지 않는다.

History rule

Promoted revisions are immutable

reopen 시 기존 r0001을 수정하지 않고 r0002를 만든다. 이전 결과는 provenance와 before/after evidence로 남는다.

Fresh-worker resume algorithm

R0 · DISCOVER
Read run.json, never conversation memory

run id, source manifest, current promotion pointer를 찾는다.

R1 · VERIFY
Re-hash receipts and promoted outputs

stale, missing, tampered artifact를 먼저 찾는다. file existence만으로 통과시키지 않는다.

R2 · FRONTIER
Find earliest invalid or incomplete stage

마지막 파일이 아니라 dependency graph의 earliest invalid frontier를 resume point로 사용한다.

R3 · RESTORE
Load promoted upstream state

tmp/와 browser ephemeral state는 버리고 authoritative artifacts만 복원한다.

R4 · EXECUTE
Continue autonomously to next gate

routine pass-by-pass approval을 요구하지 않는다. blocker나 user-intent ambiguity만 사용자에게 올린다.

R5 · REVIEW
Render exact current artifact

새 descendant를 실제 target/keyframe으로 캡처해 material mismatch를 확인한다.

R6 · CLOSE
Promote or reopen cause

PASS면 새 receipt/checkpoint. FAIL이면 issue owner를 reopen하고 downstream을 invalidate한 뒤 반복.
